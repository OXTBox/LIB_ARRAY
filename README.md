# LIB_ARRAY

`~/projects` as a whole is the **LIB_ARRAY**: the game engines, the games and the LIB_* libraries
they share (LIB_SYSTEM/LIB_ALPHA.md, line 12). This repository holds only the owner's notes about
the whole array; the rules and the map of every LIB are in `LIB_SYSTEM/LIB_ALPHA.md`, the work in
`LIB_SYSTEM/STATUS.md` and `TODO.md`.

| File | What |
|---|---|
| `Notes To Claude 756PM_11_12_2026.txt` | the owner's notes that started LIB_ALPHA (window titles, LIB_OMEGA) |
| `✳LIB_ARRAY.txt` | a saved session transcript: the request for the whole-project TODO list |
| `✳ Spark assigned work status.txt` | a saved status report of Spark's assigned work |

## Get everything

All 46 projects live in the GitHub organisation **OXTBox**. Two ways to get them all at once:

- **One zip** (a snapshot, nothing to install): the newest `LIB_ARRAY_<date>.zip` on this project's
  Releases page. Unzip it and every project is a folder side by side.
- **One command** (projects you can update and send changes back from): `./get_everything.sh`
  (Linux, Mac, WSL) or `LIB_BAT/get_everything.bat` (Windows, double-click). Run it again to update.
  It gets only the projects your GitHub account can see.
